# Topic 3: Blender Modeling for Engineering Visualization

## Theme

Create efficient 3D equipment that communicates process state clearly.

## Learning outcomes

- navigate Blender and use object/edit modes;
- model equipment with primitive and modifier workflows;
- apply scale and place origins correctly;
- follow naming and complexity conventions for real-time use.

## Preparation

- Complete the selected Blender fundamentals playlist sections.
- Collect dimensional references for the chosen process.

## Three-hour plan

| Time | Activity |
|---|---|
| 00:00-00:25 | Coordinate systems, scale, topology, and real-time constraints |
| 00:25-01:00 | Guided model: tank, pipe, valve, pump, and support frame |
| 01:00-01:25 | Origins, parenting, transforms, and meaningful object names |
| 01:25-02:35 | Team modeling sprint |
| 02:35-02:50 | Peer inspection for scale and moving parts |
| 02:50-03:00 | Export-readiness checklist |

## Laboratory

Build the minimum equipment set for the project. Separate every part that must move, rotate, change material, or expose a process state. Use meters consistently and apply object transforms.

## Deliverable

A `.blend` file containing the named, scaled, and organized equipment model plus one viewport screenshot.

## Evidence and assessment

- Dimensions are plausible and consistent
- Moving components have usable origins
- Object names describe engineering function
- Geometry is sufficient for communication without unnecessary detail

## Instructor notes

Keep artistic work subordinate to system behavior. Students may use simple materials and primitives; assessment focuses on engineering readability and export quality.
